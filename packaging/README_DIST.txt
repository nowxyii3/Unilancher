================================================================================
UniLauncher — Lanceur Universel de Jeux Vidéo pour Windows (x64)
Application 100% Autonome & Portable
Dépôt GitHub : https://github.com/nowxyii3/Unilancher
================================================================================

🚀 DÉMARRAGE RAPIDE :
1. Décompressez l'intégralité de cette archive ZIP dans un dossier de votre choix (ex: C:\Games\UniLauncher).
2. Double-cliquez sur `UniLauncher.exe` pour lancer le lanceur.
3. Aucune installation supplémentaire requise (application 100% portable).

🎮 PRINCIPALES FONCTIONNALITÉS :
- Centralisation multi-stores automatique :
  * Steam (manifestes .acf)
  * Epic Games Store (manifestes JSON)
  * GOG Galaxy (base SQLite & registre)
  * EA App, Ubisoft Connect, Battle.net et Xbox PC
- Mode Salon TV / Big Picture (Touche F10) avec support complet manette et clavier
- Recherche instantanée globale type Spotlight (Raccourci Alt + Espace)
- Suivi hebdomadaire en direct des jeux offerts et bons plans PC
- Intégration Discord Rich Presence dynamique
- 8 thèmes visuels sombres modernes et personnalisation d'interface poussée
- Sauvegarde et surveillance matérielle intégrées

⚙️ COMPATIBILITÉ & CONFIGURATION :
- Système : Windows 10 / Windows 11 (64-bit)
- Dossier de configuration et cache : %APPDATA%\UniLauncher\
- Aucune dépendance externe ni runtime lourd requis.
